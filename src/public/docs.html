1. Get a key

Every request authenticates with a managed sk-… key, created from the dashboard.

Sign in at /admin/dashboard → API keys → Create key. The value is shown once; store it somewhere real.

A key only reaches providers and subscription seats owned by your account. Someone else's key hitting the same model gets no active provider configured for model rather than a ride on your seat.

2. Base URL & auth

OpenAI-compatible. No vendor keys on the client — the gateway holds the real credential.

4. Pick a model

Routing matches the model field as a prefix against every provider you can reach, and splits traffic by weight when more than one claims it.

Two providers can claim the same model on purpose — a subscription seat plus a metered key, or two seats. Whichever is healthy and not cooling down gets the request; a failing one is retried on another automatically.

Name a provider directly with provider_id/model to skip all of that — no prefix guess, no weighting, no failover to a different credential:

{"model":"4a7f/gemini-3-pro", …}

Only the segment before the first slash has to be a provider id you can see; the rest travels through unprefixed, so groq/qwen/qwen3-32b targets the provider row groq and sends Groq the model name qwen/qwen3-32b exactly as it expects.

Or name the vendor with a short alias — codex/, claude/, grok/, anti/, kimi/ — to spread the request across every row for that vendor, keeping weighting and failover intact:

{"model":"anti/gemini-3-flash", …}

Connect a second seat on the same vendor and the alias keeps working across both, unchanged — unlike provider_id/model, which stays pinned to whichever one row you named. A real provider id always wins if it happens to collide with an alias.

6. Troubleshooting

          

          

            

              
SymptomCause

              
                
401 — Missing Authorization: BearerNo key sent, or it's somewhere other than the Authorization header.

                
no active provider configured for modelNothing you own claims that model name, or a provider_id/model target doesn't exist or can't serve this path.

                
Anthropic only authorized for use with Claude CodeVendor-side check on consumer-plan OAuth credentials used outside Claude Code. Not fixable here.

                
A seat that worked suddenly failsThe credential lapsed or was revoked. Check GET /admin/oauth/providers, then POST /admin/oauth/<id>/refresh.
